# Basic Logic Gates

## Description

The Basic Logic Gates project is a simple digital logic design implemented using Verilog HDL.

The project demonstrates the operation of fundamental logic gates including AND, OR, NOT, NAND, NOR, XOR, and XNOR.

## Features

* Implements basic logic gates
* Simple Verilog HDL design
* Includes a testbench
* Includes simulation output
* Easy to understand and simulate
* Useful for learning digital logic design

## Technologies Used

* Verilog HDL
* Digital Logic Design
* Simulation and Verification

## Logic Gates

| Gate | Operation |
| ---- | --------- |
| AND  | A & B     |
| OR   | A | B     |
| NOT  | ~A        |
| NAND | ~(A & B)  |
| NOR  | ~(A | B)  |
| XOR  | A ^ B     |
| XNOR | ~(A ^ B)  |

## Inputs

| Signal | Description  |
| ------ | ------------ |
| `A`    | First input  |
| `B`    | Second input |

## Outputs

| Signal      | Description      |
| ----------- | ---------------- |
| `AND_gate`  | AND gate output  |
| `OR_gate`   | OR gate output   |
| `NOT_gate`  | NOT gate output  |
| `NAND_gate` | NAND gate output |
| `NOR_gate`  | NOR gate output  |
| `XOR_gate`  | XOR gate output  |
| `XNOR_gate` | XNOR gate output |
